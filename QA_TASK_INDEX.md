## Task 3: Install Node.js, Docker, npm, VS Code, and Antigravity

**Status:** ✅ Completed 17-May

### Objective

Install the core developer tools required for local development, containerization, and workflow automation.

### Tools Installed

- Node.js
- npm (included with Node.js)
- Docker
- Visual Studio Code
- Antigravity

### Installation Steps

1. Installed **Node.js** from the official website: [https://nodejs.org/](https://nodejs.org/)

2. Installed **Docker Desktop** from [https://www.docker.com/get-started](https://www.docker.com/get-started)
   - Verified installation with `docker --version`.

3. Installed **Visual Studio Code** from [https://code.visualstudio.com/](https://code.visualstudio.com/)
   - Opened VS Code and confirmed it launched successfully.

4. Installed **Antigravity**.
   - Followed the official installation or package instructions for Antigravity.
   - Verified the installation by launching the Antigravity application or running its version command if available.

### Result

All required development tools are installed and verified for a productive QA and development environment.

### Notes

- Ensure Docker Desktop is running before using containers.
- Keep Node.js, npm, and VS Code updated to the latest stable versions.
